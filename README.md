# Dinesh Sekar Portfolio

A responsive, dependency-free static portfolio built with HTML, CSS and JavaScript. No installation, build process, server or API key is required.


## Publish on GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`, replacing YOUR-USERNAME with your actual GitHub username.
2. Upload the CONTENTS of this folder into the repository root, including `index.html`, `styles.css`, `script.js`, `.nojekyll` and the `assets` folder. Do not upload the ZIP itself or leave everything inside an extra parent folder.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch. Select `main` and `/ (root)`, then Save.
5. Wait for GitHub's deployment to complete. Open `https://YOUR-USERNAME.github.io/`.

For a project repository with another name, the address is `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`. Relative asset paths support either approach.
Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Files and editing
- `index.html`: profile, projects, experience, skills, credentials and contact details.
- `styles.css`: colors, typography, desktop/mobile layout and print styles.
- `script.js`: mobile navigation and footer year.
- `assets/Dinesh_Resume.docx`: downloadable resume. Replace with your updated resume using the same filename or change the download links.
- `assets/favicon.svg`: DS browser icon.
- `.nojekyll`: publishes these files directly.

Search `index.html` for a heading or sentence to edit its content. Project details use native `<details>` elements. All important content remains visible without JavaScript. This is a professional portfolio, not a live DNS/IPAM tool; no infrastructure API is connected.
